# Griffin Eaves — Official Author Website

A responsive author portfolio website created for Griffin Eaves. The site presents his books, individual book details, first-chapter previews, author information, and representative contact details.

## Live website
Pages
- index.html — Home page
- books.html — Four-book catalogue
- book.html — Individual book details
- about.html — About Griffin Eaves
- contact.html — Contact page for press, rights and collaborations
- chapters/ — Individual first-chapter reading pages
Features
- Responsive design for desktop and mobile
- Individual pages for each book
- First-chapter previews
- Custom book-cover images
- Author portrait sections
- Direct Gmail contact link
- Clean editorial style
Built with
- HTML5
- CSS3
- JavaScript
- Google Fonts
